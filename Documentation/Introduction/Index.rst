About this document
===================

TYPO3 provides different ways to create multilingual websites.
This guide explains these ways and the features involved, so that you
can choose the one that fits your project.

For the exact syntax of a feature, see, for example,
`TypoScript Reference <https://docs.typo3.org/permalink/t3tsref:start>`_ and
`TYPO3 Explained <https://docs.typo3.org/permalink/t3coreapi:start>`_.


..  _about-terms:

Localization and translation
----------------------------

These two terms often denote the same thing. However, they differ as follows:

Translation
    A second page with the same content as the first, but in another language.
    If a page in the default language has a header and an image, its translation
    will also have a header and an image.

Localization
    A page for the audience of another language. It can have different content,
    images, or a different template in addition to the translated text. It can
    have more or less content elements than the page in the
    default language.

TYPO3 supports both of these. To choose between them, see
`Localized content <https://docs.typo3.org/permalink/t3translate:localized-content>`_.
